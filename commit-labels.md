# Commit message labels

Keep commit messages short and concise. Start with one of these labels, a
colon, and a brief description:

| Label | Use for |
| --- | --- |
| `feat` | A new feature |
| `fix` | A bug fix |
| `refactor` | Code cleanup or restructuring with no behavior change |
| `docs` | Documentation changes |
| `test` | Test changes |
| `chore` | Maintenance, dependencies, or build configuration |

Examples:

```text
feat: add interactive dye injection (#123)
fix: preserve velocity at the domain walls
refactor: simplify mouse input mapping
docs: document commit message labels
test: cover pressure projection
chore: update CMake configuration
```

Add an issue reference such as `(#123)` when the commit relates to one.
