# Commit messages

Use `<label>: <short description>`. Add `(#123)` when relevant.

- `feat`: New feature
- `fix`: Bug fix
- `refactor`: Cleanup or restructure without behavior changes
- `docs`: Documentation
- `test`: Tests
- `chore`: Maintenance, dependencies, or build configuration

Git-generated merge subjects such as `Merge branch ...` and
`Merge pull request #123 from ...` are exempt.

Example: `feat: add a feature (#123)`
